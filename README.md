# Ruta EV

Planificador personal de viajes para Kia EV3. Versión de desarrollo en pruebas.

Necesita una clave propia de Open Charge Map, introducida en Ajustes y guardada en el navegador. Los tiempos y consumos son estimaciones; no incluye tráfico ni disponibilidad en tiempo real de cargadores.

Los datos del navegador usan el prefijo `rutaev:` para separarlos de otras aplicaciones.
